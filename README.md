# Quantum Software Engineering

A structured portfolio documenting my journey through quantum computing, from the fundamentals of qubits to modern quantum algorithms and quantum software development using **Python** and **Qiskit**.

This repository contains a series of Jupyter notebooks covering both the theoretical concepts and practical implementation of quantum computing, along with reusable Python modules for common algorithms and utilities.

## Topics Covered

### Foundations

- Quantum Circuits
- Classical Bits vs Qubits
- Hilbert Space
- Quantum Gates
- Superposition
- Measurement
- Statevectors
- Bloch Sphere
- Rotation Gates

### Multi-Qubit Systems

- Tensor Products
- CNOT Gate
- Bell States
- Quantum Entanglement
- Quantum Teleportation

### Quantum Algorithms

- Grover's Search Algorithm
- Quantum Fourier Transform (QFT)
- Variational Quantum Eigensolver (VQE)
- Shor's Algorithm

### Quantum Software Development

- Simulators vs Hardware
- Transpilation
- Circuit Optimization
- Gate Decomposition
- Backend Properties
- Noise & Error Mitigation
- Resource Estimation
- Reusable Quantum Libraries
